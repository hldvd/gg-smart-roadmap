## قواعد دسترسی و به‌روزرسانی

### دسترسی عمومی
- اسناد این بسته برای همگان قابل دسترسی هستند
- اطلاعات حساس (شناسهٔ شبکه، توکن‌ها، گذرواژه‌ها) نباید وارد این بسته شوند
- اسناد تخصصی در مخزن خصوصی می‌مانند

### به‌روزرسانی اسناد
- تغییرات باید با درخواست صریح انجام شود
- تغییرات در اسناد تخصصی باید با توجه به تأثیر بر اسناد عمومی بررسی شوند
- تاریخ به‌روزرسانی هر سند ثبت می‌شود

### پیوند بین اسناد
- از پیوندهای داخلی برای ارجاع بین اسنادِ **همین بسته** استفاده شود
- به اسناد خصوصی فقط به‌صورت ارجاع متنی (بدون لینک) اشاره شود
